### Other DumpTree files
Like the main dumpTree files, these files parse the hit and trajectory information from an output of `edep-sim`, and in turn output a file with kinematic information from each event, including true and reco quantities. The main dumpTree files output the info in a format that can be input to CAFMaker, resulting in a final CAF file that can be used for analyses. The output of these files is similar, but often includes more information that is used for analyzing changes made to the original dumpTree files. The exception to this is `dumpTree_hits.py`, which outputs a tree in which each line corresponds to a hit rather than an event. Saved hit information includes its location, if it's in an active region of the detector, the material it's in, its length, the amount of energy it deposited, and the particle that created it.
