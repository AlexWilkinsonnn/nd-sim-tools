### Other EhadCorr Produce Scripts
Like the main produce scripts, these files run a full ND simulation and parametrized reconstruction, but modified slightly for investigating the hadronic energy reconstruction differences between LArbath and the full ND geometry. 
- `produce_edep_hits_ND_larbath.sh`: This runs `GENIE`, `edep-sim`, but then sends the `edep-sim` files to `dumpTree_hits.py` for processing of hit-level information from the edep-sim files.
- `produce_Ehadcorr_edep-paramreco_larbath_transrots_tdr.sh`: This runs `GENIE`, `edep-sim`, then sends the `edep-sim` output to several different dumpTree files for processing. The different dumpTree files contain different iterations of the Ehad reco density correction, so this file allows all of those to be compared at once. In each case the `dumpTree` outputs are fed into a special version of CAFMaker so that the extra diagnostic variables can be propagated to the final CAF file while all of the other reconstruction is preserved.
